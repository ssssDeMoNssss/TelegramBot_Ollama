# Telegram Bot для OLLAMA

## Описание
Telegram-бот для интеграции с OLLAMA, включая автоматизацию через .BAT-файлы.

## Установка
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/ssssDeMoNssss/TelegramBot_Ollama.git
   ```
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Запустите скрипт `setup.bat` для настройки окружения.

## Использование
- Запустите бота:
  ```bash
  python bot.py
  ```
